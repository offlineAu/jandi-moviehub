# Streaming master plan

Status: IN_PROGRESS (2026-11-01). Preserve the existing licensed-asset catalog, room sync and marathon engine.

1. Add independent, cached TV metadata discovery and season details; never infer playback rights.
2. Add regional availability adapters with explicit configuration, source attribution and safe external links.
3. Extend playback only for providers with documented authorization, preserving server-authoritative rooms.
4. Exercise actual full-length licensed playback, failover and multi-client recovery; report only measured results.
5. Validate administration, security and deployment. Credentials, agreements and geo enforcement remain external dependencies.
